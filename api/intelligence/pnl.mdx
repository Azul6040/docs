title: "GET /api/v1/intelligence/pnl"
sidebarTitle: "P&L Statement"
description: "Retrieve the full income statement for a period: revenue, COGS, gross profit, operating expenses, EBITDA, and net profit with benchmark statuses."
---

The P&L endpoint returns the complete income statement for the selected period, calculated by combining the sales data your POS pushes with purchases and payroll entered directly in the Restaurantero Pro dashboard. Each section carries a benchmark `status` field so you can surface green/yellow/red indicators directly in your UI without any additional computation.

## Request

```http
GET /api/v1/intelligence/pnl
X-API-Key: rpro_live_abc123xyz789...
```

## Query parameters

<ParamField query="branch_identifier" type="string" required>
  UUID of the branch to query.
</ParamField>

<ParamField query="date_from" type="string" required>
  Start of the period (`YYYY-MM-DD`). Omit if using `period`.
</ParamField>

<ParamField query="date_to" type="string" required>
  End of the period (`YYYY-MM-DD`). Omit if using `period`.
</ParamField>

<ParamField query="period" type="string">
  Period shortcut: `today`, `yesterday`, `week`, or `month`.
</ParamField>

### `meta.benchmarks`

The `meta` object includes the benchmark thresholds used to calculate each status field.

```json
"benchmarks": {
  "food_cost":   { "green": "< 30%", "yellow": "30-38%", "red": "> 38%" },
  "labor_cost":  { "green": "< 30%", "yellow": "30-35%", "red": "> 35%" },
  "prime_cost":  { "green": "< 60%", "yellow": "60-65%", "red": "> 65%" },
  "ebitda":      { "green": "> 20%", "yellow": "10-20%", "red": "< 10%" }
}
```

## Cash flow — `GET /api/v1/intelligence/cash-flow`

The Cash Flow endpoint is the digital cash ledger for the restaurant. It shows every cash inflow and outflow for the period — including cash sales, deposits received, purchases paid in cash, tips paid to servers, and withholdings — alongside the opening balance, closing balance, and a daily breakdown with variance status.

<Note>
  This endpoint tracks **cash movement only**. Card and transfer sales do not appear in inflows or outflows because they do not move physical cash.
</Note>

### Request

```http
GET /api/v1/intelligence/cash-flow?branch_identifier=b1c2d3e4-f5a6-7890-abcd-ef1234567890&date_from=2026-05-01&date_to=2026-05-15
X-API-Key: rpro_live_abc123xyz789...
```
