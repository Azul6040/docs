---
title: "GET /api/v1/intelligence/alerts"
sidebarTitle: "Alerts"
description: "Retrieve prioritized KPI alerts for a period — food cost overruns, cash variances, cancellation anomalies, and positive sales trends."
---

The Alerts endpoint returns a prioritized list of financial and operational alerts generated for the selected period. Alerts are calculated automatically after each Corte Z and cover both risk signals (food cost overruns, cash shortfalls, excessive voids) and positive signals (sales growth). Use this endpoint to drive notification banners, alert feeds, or priority action lists in your POS dashboard.

## Request

```http
GET /api/v1/intelligence/alerts
X-API-Key: rpro_live_abc123xyz789...
```

## Query parameters

<ParamField query="branch_identifier" type="string" required>
  UUID of the branch to query.
</ParamField>

<ParamField query="date_from" type="string" required>
  Start of the period (`YYYY-MM-DD`). Omit if using `period`.
</ParamField>

<ParamField query="date_to" type="string" required>
  End of the period (`YYYY-MM-DD`). Omit if using `period`.
</ParamField>

<ParamField query="period" type="string">
  Period shortcut: `today`, `yesterday`, `week`, or `month`.
</ParamField>

## Response fields

<ResponseField name="data.attributes.total_count" type="integer">
  Total number of alerts for the period.
</ResponseField>

<ResponseField name="data.attributes.critical_count" type="integer">
  Number of red-severity alerts.
</ResponseField>

<ResponseField name="data.attributes.warning_count" type="integer">
  Number of yellow-severity alerts.
</ResponseField>

<ResponseField name="data.attributes.info_count" type="integer">
  Number of informational (blue) alerts.
</ResponseField>

<ResponseField name="data.attributes.alerts" type="array">
  List of alert objects, ordered by severity (most critical first).

  <Expandable title="Alert object properties">
    <ResponseField name="id" type="string">
      Unique alert identifier (UUID).
    </ResponseField>
    <ResponseField name="severity" type="string">
      Alert severity level: `red` (critical risk), `yellow` (caution), or `blue` (positive / informational).
    </ResponseField>
    <ResponseField name="type" type="string">
      Machine-readable alert type. See the alert types table below.
    </ResponseField>
    <ResponseField name="title" type="string">
      Short display title for the alert.
    </ResponseField>
    <ResponseField name="message" type="string">
      Full alert message with context and specific values.
    </ResponseField>
    <ResponseField name="action" type="string">
      Recommended action to resolve the alert. `null` for informational alerts.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the alert was generated.
    </ResponseField>
  </Expandable>
</ResponseField>

## Alert types

| type | Typical severity | Description |
|---|---|---|
| `food_cost_high` | yellow / red | Food cost percentage has exceeded the benchmark threshold |
| `bar_cost_high` | yellow / red | Bar cost percentage has exceeded the benchmark threshold |
| `labor_cost_high` | yellow / red | Labor cost percentage has exceeded the benchmark threshold |
| `cash_variance_high` | yellow / red | Cash shortfall or overage exceeds the acceptable variance range |
| `discounts_high` | yellow / red | Discount amount or frequency is unusually high for the period |
| `cancellations_high` | yellow / red | Cancellation rate has exceeded the normal threshold |
| `void_alert` | yellow / red | Suspicious void patterns detected for a specific user |
| `low_stock` | yellow | An ingredient has dropped below the recommended minimum stock level |
| `sales_up` | blue | Sales for the period exceeded the prior equivalent period |
| `sales_down` | yellow / red | Sales for the period fell short of the prior equivalent period |

<Note>
  For real-time alerts during an active shift (discounts, voids, cash balance), use the [Live Alerts](/api/live/alerts) endpoint instead. Intelligence alerts are computed after the Corte Z and reflect the closed period.
</Note>
